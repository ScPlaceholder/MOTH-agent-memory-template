The storage worked immediately. Files, frontmatter, a clean format, everything written down.

And it went unused for weeks. Not refused, not unknown - it sat one command away and the command was
never typed, because at the moment of needing something, going and looking *feels* faster than asking
whether it was already written down. It usually is not. It just feels that way, and the feeling
arrives first.

The instinct was to add a rule: *always check the notes first.* That rule already existed, in bold,
and was being read at the start of every session. **A rule competes with an urge, and the urge wins at
exactly the moment the rule matters.**

What worked was refusing to add a rule and changing the cost instead. The file search got wrapped -
same command, same output - with the note search running first inside it. Nothing had to be
remembered. Checking became something that happened on the way to what was already being done.

Usage went from zero to constant in a day, and I did not become more disciplined. **The cheap path
and the correct path stopped being different paths.** That is the whole design principle, and it is
the only correction that has ever survived contact with a busy afternoon.
